# LLM 输出质量评估（阶段 5.7）

本页定义考古 LLM 断代/鉴定输出的质量评估体系，含**自动化指标**与**专家盲评评分卡**。

## 1. 自动化评估

脚本 `src/artifact_scan/llm_eval.py` 对一组测试文物图片调用 Ollama 模型，提取其断代/文化结论，与标注真值比对。

```powershell
# 采样 10 件带图文物（随机，可复现）
python -m artifact_scan.llm_eval --n 10 --model qwen2.5-vl:3b --out data/eval/base_qlora.json

# 指定固定测试集（便于前后对比）
python -m artifact_scan.llm_eval --ids 94979 451715 125249 --model qwen2.5-vl:3b --out data/eval/base.json
```

### 输出指标

| 指标 | 含义 |
|---|---|
| `culture_exact_acc` | 文化归属**完全一致**准确率 |
| `culture_contains_acc` | 文化归属**包含匹配**（gt/pred 互为子串）准确率 |
| `period_exact_acc` | 年代**完全一致**准确率 |
| `period_contains_acc` | 年代**包含匹配**准确率 |
| `n` | 有效样本数 |

> 模型输出已按提示词要求返回紧凑 JSON；对自由文本做了首/末 `{}` 抽取兜底。匹配做了归一化（小写/去空格）。`contains` 用于缓解模型用词差异（如「美国」vs「America」）。

### 用法说明
- 用 `--ids` 固定测试集，可对 **基座模型** 与 **LoRA 微调模型**（5.6 产物）跑同一批图，进行前后对比。
- 报告写入 `data/eval/*.json`（含逐条 raw 输出，便于人工复查）。

## 2. 专家盲评评分卡

自动化指标以标注为真值，只能反映「与标注的一致度」；对**鉴定合理性、论证质量**需考古专家盲评。

### 盲评流程
1. **打乱**：将模型输出与图片混合打乱，去掉模型来源信息（盲评）。
2. **评分**：专家按以下维度对每份鉴定评 1–5 分。
3. **汇总**：平均分、各维度分项、以及「是否认可主要结论」。

### 评分维度（1–5 分）

| 维度 | 说明 | 1 | 5 |
|---|---|---|---|
| **年代判断合理性** | 结论与文物风格的匹配度 | 明显错误 | 准确且有据 |
| **文化归属准确性** | 文化/地域判断 | 错误 | 准确 |
| **论证依据充分性** | 是否给出可支撑的器型/纹饰/材质依据 | 无依据 | 依据充分 |
| **术语专业性** | 考古术语使用是否专业准确 | 口语化/错误 | 术语准确 |
| **输出结构清晰度** | 是否条理清晰、可读 | 混乱 | 结构清晰 |
| **整体可用性** | 是否可作为鉴定参考 | 不可用 | 直接可用 |

### 记录格式

```
文物ID | 年代分 | 文化分 | 依据分 | 术语分 | 结构分 | 整体分 | 认可结论?(Y/N) | 备注
```

### 用途
- 自动化指标提供**客观一致度**，盲评提供**专业合理性**，两者结合避免单一偏差。
- 建议对「基座模型」与「LoRA 微调模型」各跑一轮，比较提升。
